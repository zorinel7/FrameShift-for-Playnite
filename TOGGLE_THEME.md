# Toggle Theme for FrameShift

FrameShift's Playnite Fullscreen integration requires the **Toggle – Zorinel / FrameShift Fork** theme.

Theme repository:
https://github.com/zorinel7/Toggle-Zorinel-FrameShift

The Toggle fork provides the FrameShift button in the Fullscreen game details view and contains the matching FrameShift localization integration.

Install both projects:
1. FrameShift
2. Toggle – Zorinel / FrameShift Fork

After installation, restart Playnite and open a game's details page in Fullscreen Mode.

The Toggle fork keeps the original Toggle appearance and core behavior while adding FrameShift integration and localization support.
