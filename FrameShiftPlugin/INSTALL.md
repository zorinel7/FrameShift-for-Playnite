# FrameShift — Plugin Installation

1. Open `FrameShift_<version>.pext` with Playnite and restart Playnite.
2. Confirm the FrameShift prompt and the UAC prompt to install the RTSS bridge.

The bridge is copied to `%ProgramFiles%\FrameShift` and registered as the `FrameShift RTSS Bridge` scheduled task.
Before uninstalling the add-on, use **Main menu → Extensions → FrameShift → Remove RTSS bridge**.

Manual alternative: run `Install-FrameShift.cmd` / `Uninstall-FrameShift.cmd` from this folder as Administrator.
